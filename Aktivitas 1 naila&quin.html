🏎️ Aktivitas 1 — Prediksi

let a = 10; let b = 5; console.log(a + b); console.log(a - b); console.log(a * b); console.log(a / b);
Operasi Prediksi Hasil Sebenarnya
a + b 15 15
a - b 5 5
a * b 50 50
a / b 2 2

Apakah prediksi kamu benar? Ya.

Mengapa? Karena hasil operasi dapat dihitung menggunakan operator aritmatika yang sesuai.

🔧 Aktivitas 2 — Eksperimen

let a = 20; let b = 4; console.log(a + b); console.log(a - b); console.log(a * b); console.log(a / b); console.log(a % b);

Prediksi:

a + b = 24
a - b = 16
a * b = 80
a / b = 5
a % b = 0

Apa yang kamu temukan?

Operator % digunakan untuk mencari sisa pembagian. Karena 20 dapat dibagi 4 tanpa sisa, hasilnya adalah 0.

📡 Aktivitas 3 — Input dengan prompt()

let nama = prompt("Masukkan nama:"); console.log(nama); let umur = prompt("Masukkan umur:"); console.log(umur);

Apa fungsi prompt()?

prompt() berfungsi untuk meminta atau menerima input dari pengguna.

⏱️ Aktivitas 4 — Menghitung Umur

let tahunLahir = prompt("Masukkan tahun lahir:"); let tahunSekarang = 2026; let umur = tahunSekarang - tahunLahir; console.log(umur);

💰 Aktivitas 5 — Mesin Kasir Mini

let harga = prompt("Masukkan harga:"); let jumlah = prompt("Masukkan jumlah:"); let total = harga * jumlah; console.log(total);

Uji:

Harga = Rp5.000
Jumlah = 4

Total = Rp20.000

🐞 Aktivitas 8 — Debugging

let harga = 5000; let jumlah = 3; let total harga = harga * jumlah; console.log(total harga);

Kesalahan:

Nama variable tidak boleh menggunakan spasi. "total harga" menyebabkan syntax error.

Perbaikan kode:

let harga = 5000; let jumlah = 3; let totalHarga = harga * jumlah; console.log(totalHarga);
